# Avenir Solutions website

Static site for avenirsolutions.in (AM/NS-inspired layout, blue & white theme). Built from the
generator kept in `Desktop\Personal\Avenir\Website Redesign\avenir-site` (run `src\build.py`,
then copy the contents of `dist\` here). All links are relative, so the same files work on
GitHub Pages and on Hostinger.

Pages: home, products (manufacturing), mro, materials, about, contact, blog (11 posts),
tools/material-weight-calculator, manufacturing/engineering-plastics, manufacturing/rubber-cords,
products/elastomers-rubber-components, products/mro/ss-304-camlock-coupling,
products/mro/tajima-quick-dry-ink, privacy-policy, terms, 404.
